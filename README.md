# 🧭 Thapar Wayfinder

### Interactive 3D Campus Navigation & Information Platform

> **Find Places. Find People. Find Your Way.**

Thapar Wayfinder is a web-based campus navigation project being developed to help students and visitors locate buildings, departments, classrooms, campus facilities, and faculty cabins within the Thapar campus.

The project is currently **under development**.

---

## 🎯 Project Idea

The aim of Thapar Wayfinder is to provide a centralized platform where users can:

- Explore the Thapar campus using an interactive 3D map
- Locate buildings and departments
- Find classrooms and campus facilities
- Search for faculty members
- Find faculty cabin locations
- Access official Thapar faculty profiles
- Navigate between campus locations

**Outcome:**  
The idea of developing a dedicated Thapar campus navigation platform was finalized.

---

## Week 2 — Technology Exploration

- Researched different map technologies.
- Explored alternatives such as Leaflet and Mapbox.
- Studied Mapbox GL JS.
- Explored Mapbox Studio.
- Investigated 3D building visualization.
- Discussed the feasibility of using Mapbox within its available development limits.

**Outcome:**  
Mapbox was selected as the primary mapping technology.

- Successfully loaded the Thapar campus map locally.
